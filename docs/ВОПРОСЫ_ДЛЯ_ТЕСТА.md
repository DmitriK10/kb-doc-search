## Часть 2. Десять вопросов по важным темам

### 1. Сроки пресейла — развилка
```
какой срок инициации заявки на пресейл
```
**Ожидается:** плашка «НУЖНО УТОЧНЕНИЕ», два срока (ТЗТ п. 1.5 — 2 недели
до конкурса; ДБРЦТ п. 1.5 — 3 рабочих дня до предложения) и опция
«создадим запрос в службу качества».

### 2. Кто назначает РП — междокументное расхождение
```
кто назначает руководителя проекта
```
**Ожидается:** развилка «На этапе пресейла» / «В проекте».
После выбора — цитата, а в ветке «пресейл» обе формулировки:
ТЗТ п. 4.1 и ДБРЦТ п. 2.1.2.

### 3. Каскад хардоффера — три уровня
```
заказчик выбрал продукт и запрашивает только расчёт поставки
```
**Ожидается:** каскад вопросов про хардоффер и долю услуг.
**Пройдите до конца** — финальная цитата п. 1.3 Пресейл ДИБ.

### 4. Английский перефраз — паттерн заказчика
```
who appoints the project manager
```
**Ожидается:** развилка (находит расхождение про РП).

### 6. Числовой ответ — ИЗВЕСТНЫЙ ДЕФЕКТ
```
сколько подрядчиков запрашивает TPS
```
**Правильный ответ:** **п. 2.12** — «TPS запрашивает у Департамента по
работе с подрядчиками потенциальных подрядчиков для выполнения работ
(не менее 3-х)».
**Что вернёт система:** п. 2.11 — «За выбор подрядчика на этапе пресейла
отвечает TPS». Соседний пункт: слово «подрядчик» есть, числа нет.
**Это дефект поиска, не регрессия.** В видео не используется.

### 7. Два похожих правила — проверка точности
```
что делать если автор заявки не ответил 3 рабочих дня
```
**Правильный ответ:** **п. 3.4** Пресейл ДИБ — статус
«Дисквалифицировано» через 3 рабочих дня.
**Внимание:** если вернётся «5 рабочих дней» и «Отклонён» — это
Проектная ДИБ п. 2.3, **другое правило** (нет ответа от SS, не от автора).
Отметьте, что пришло.

### 8. Срок назначения — ИЗВЕСТНЫЙ ДЕФЕКТ

## Урок про фидбек

На прогоне пользователь нажал «Помогло» на ответах **п. 10.3** (Q8)
и **п. 2.11** (Q6). Оба содержат **неверный пункт** — правильно 9.1
и 2.12.

**Фидбек реагирует на полезность, но не гарантирует точность цитаты.**
«Помогло» — сигнал, куда смотреть, а не доказательство корректности.
Точность проверяется только сверкой с текстом регламента.

## Ограничения измерений

**«Отказов при найденном gold = 0»** — измерено на n=59 dev / n=40 test.
Это факт на этих вопросах, **не гарантия** для новых. Набор мал.

**Сессии ≠ пользователи:** сессия — серия запросов в рамках одного
идентификатора в браузере. Один человек с двух браузеров даст две сессии.
Число людей по сессиям не считается.
